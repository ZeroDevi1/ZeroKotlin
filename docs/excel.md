# Excel 导入导出

用户和字典页面提供模板下载、导入和导出。字典项在指定字典的「全部字典项」视图中操作。导入成功后页面刷新对应列表。

## 填写模板

下载对应模板，在第 2 行起填写数据并保存为 `.xlsx`。保留首行和列顺序，保留文本列格式，使用一张可见工作表。空白行会跳过，公式、错误单元格、宏及额外数据列会被拒绝。

| 资源 | 模板列 | 填写规则 |
| --- | --- | --- |
| 用户 | 用户名、显示名称、初始密码、部门 ID、角色 ID | 前三列必填。用户名按小写保存。每行填写该账号的初始密码，至少 12 个 Unicode 码点且最多 72 个 UTF-8 字节。部门可留空，角色可留空或填写以半角逗号分隔的业务角色 ID，最多 256 个，不能分配内置管理员角色。新账号默认启用。 |
| 字典 | 字典编码、字典名称 | 两列必填。字典编码唯一，新字典默认启用。 |
| 字典项 | 值、标签、排序、启用 | 值和标签必填。值在目标字典内唯一。排序是 32 位整数，默认 `0`。启用接受 `TRUE`、`FALSE`、`1` 或 `0`，默认启用。 |

用户数据可填写在第 2～101 行，字典和字典项可填写在第 2～1001 行。上传文件最大 1 MiB，ZIP 内部最多 64 个条目，解压总大小最多 16 MiB。部署侧的 multipart 或反向代理限制可能更小。

导入只新增记录。用户名、字典编码和字典项值按对应创建接口的规则核验，文件内重复和与数据库重复均会报错。格式或业务校验失败返回 HTTP 400，重复返回 409，超出文件或解压限制返回 413。行级错误会报告 Excel 行号和原因。任何一行失败都会回滚整批写入，包括账号角色关联和操作审计。含初始密码的上传文件应按凭据文件保管。

## 接口与权限

接口前缀为 `/api/system`。从下表选择资源路径，追加 `/excel/template`（GET）、`/excel/import`（POST）或 `/excel/export`（GET）。导入使用 `multipart/form-data` 的 `file` 字段，成功返回 HTTP 201 和 `{"imported":3}`。下载返回 XLSX 附件。

| 资源路径 | 模板下载和导入 | 导出 |
| --- | --- | --- |
| `/users` | `system:user:manage` 且为内置管理员 | `system:user:read` |
| `/dictionaries` | `system:dictionary:write` | `system:dictionary:read` |
| `/dictionaries/{dictionaryId}/items` | `system:dictionary:write` | `system:dictionary:read` |

用户导出应用读取权限的数据范围和可选 `departmentId`、`roleId` 筛选。导出列为用户 ID、用户名、显示名称、部门 ID、启用、角色 ID。字典导出列为字典 ID、字典编码、字典名称、启用。字典项导出列为字典项 ID、值、标签、排序、启用，只包含指定字典内的条目。字典和字典项导出均含停用记录。

每次导出最多 1000 条，超限返回 HTTP 400。导出按固定列生成，省略初始密码、密码哈希和令牌。模板与导出下载各写一条操作审计，成功导入的记录沿用各资源的创建审计。
